# 《浮生录》（Lifepath）· 时代浪潮与真实文字人生模拟器

> “一个人的命运，既要靠自我的奋斗，亦要看历史的进程。时代洪流呼啸而过，偶发的幸与不幸如影随形。唯心自守，落子无悔。”

---

## 核心系统升级与游戏特色

### 1. 天命降生系统（初始随机性）
- **随机年代投放**：可随机投胎于 1976（文革暮年）、1982（改革春风）、1988（商品狂潮）、1994（南巡后下海潮）等不同时代节点。
- **多元家庭阶层底色**：三线内陆国企职工大院、黄土丘陵偏远农家、省城书香教师、沿海敢闯个体户、单亲下岗缝纫女工等，决定了初始财富、抗压能力与见识视野。
- **先天命格与特质词条**：天生神力、灵光乍现、福泽深厚、钝感心安、商海通达等多重天赋词条，带有先天的体魄与气运修正。
- **一键重新摇号（Roll 点）**：开局支持无限次重新洗练命格，体验不同起点的开局。

### 2. 宏大时代缩影（1970s - 2020s+ 历史进程）
- 每一个阶段的选择都与中国近半个世纪的历史大事件深度耦合：
  - **1980s-1990s**：物价闯关、停薪留职、下海经商、国企下岗阵痛；
  - **2000s**：千禧入世（WTO）、外贸狂飙、互联网早期萌芽、做题家竞争；
  - **2008-2015**：北京奥运、四万亿基建、房地产与学区房暴涨、大众创业与移动互联风口；
  - **2020s-2030s**：经济去杠杆与行业收缩、大厂优化与降本增效、生成式 AI 大潮与老龄化深度来临。

### 3. 强随机性（Stochastic Dice Mechanics）
- **实时胜率与掷骰判定**：选项分为“确定性稳扎稳打”（100%必成）与“博弈冒险”（带成功率，由悟性、气运与时代动态影响），现场 Roll 点判定（1-100）。顺遂则跃升阶层，受挫则陷入被动。
- **突发偶发事件（Random Encounters）**：岁月流转间有 35% 几率遭遇突发的无常变故（如彩票小奖、突发急症手术、老友借贷失联、贵人偶然提携、股市行情剧震等）。

### 4. 深刻终局：人物一生总结系统
- **六维数据终生量化**：生命健康（Health）、积累财富净值（Wealth，支持负债统计）、学识智识（Wisdom）、心境安宁（Peace）、天命气运（Fortune）。
- **宿命评定与墓志铭**：基于终生综合表现判定《时代弄潮翁》、《负重攀登者》、《旷达布衣》、《清醒明哲者》、《断弦流星》、《人间守望者》等终极称号及深沉墓志铭。
- **时代坐标长河评析**：宏观剖析主角在当代现代化转型大浪淘沙中的个人位置（大历史 × 小人物）。
- **生平纪传与分水岭复盘**：自动生成如同小说自传般的纪传体文本，并列出每一个关键分水岭的掷骰实录与决策回响。

## 启动与体验方式

本项目支持 **双端开箱即用**，均无任何第三方依赖。

### 方式一：网页端体验（推荐，视觉效果与 Web Audio 音效最佳）
直接在现代浏览器中打开 [index.html](index.html)：
- 拥有纸墨暗黑质感排版、六维实时属性栏、时代横幅提示、命运掷骰动效。
- 内置零依赖离线 Web Audio 音效引擎，提供真实的抉择声与终局钟鸣。
- 支持一键将“人物一生生平档案”复制到系统剪贴板。

也可以使用本地静态服务器启动：
```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

### 方式二：终端命令行体验（纯 Python 3，零外部依赖）
在终端中直接运行 [life_game.py](life_game.py)：
```bash
python3 life_game.py
```
- 包含 ANSI 终端彩色排版、打字机节奏感输出、交互式掷骰检定与终局盖棺定论。
