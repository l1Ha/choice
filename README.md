# 《浮生录》（Lifepath）· 文明长河文字人生模拟器

> “一个人的命运，既要靠自我的奋斗，亦要看历史的进程。时代洪流呼啸而过，偶发的幸与不幸如影随形。唯心自守，落子无悔。”

## 核心系统与全新特性

### 1. 五大文明纪元 · 从华夏溯源到星海跃迁

出生年份可在 **公元前 2070 年 ~ 公元 2150 年** 之间全域随机（横跨 4220 年），出生月份亦随机（1–12 月）。
纪元只是“投胎的起点”，不是人生的边界——**一生会随年代推移自动切换时代背景与事件池**。

| # | 纪元 | 区间 | 时代底色 |
|---|------|------|----------|
| 1 | ⚱️ 先秦汉唐 · 华夏奠基 | 公元前 2070 – 公元 907 | 上古传说、夏代肇兴、殷商甲骨、春秋百家、秦扫六合、两汉丝路、魏晋门阀、盛唐万邦 |
| 2 | 🏮 宋韵明清 · 市井千帆 | 公元 960 – 1911 | 汴京瓦舍、市舶刺桐、大元驿道、大明远洋、康乾与晚清危局 |
| 3 | 🌅 近代破晓 · 烽火涅槃 | 公元 1912 – 1977 | 民国风雷、烽火抗战、建国筑基、大庆精神、红砖岁月、春风破冰 |
| 4 | 🏙️ 当代腾飞 · 浪潮狂飙 | 公元 1978 – 2035 | 真理讨论、特区拔地、南方谈话、世贸扬帆、移动互联、生成式 AI |
| 5 | 🚀 未来星海 · 戴森纪元 | 公元 2036 – 2150 | 常温超导、太空天梯、神经脑机、火星农业、硅基共治、恒星际点火 |

- **无间断时代解析器**：内置 43 段「大时代背景」区间表，从 `上古传说 · 三皇五帝`、`夏代肇兴 · 禹画九州` 到 `戴森云环 · 终幕跃迁`，
  覆盖 −∞ 至 +∞。任意年份（含公元前）都必然落在某个具体时代里，不存空洞。
- **一生可穿越十几重时代**：例如一位生于 1970 年的人，会依次走过红砖岁月 → 春风破冰 → 南方谈话 →
  世贸扬帆 → 移动互联 → 智算新质 → 太空天梯……直到 2050 年代。大历史 × 小人物的年轮由此显现。
- **完全随机天命**：开局可自主挑选五大纪元之一，也可一键让命运掷骰，随机投放到任一纪元与任一年份。

### 2. 程序化出身：每纪元 8 地域 × 10 门第 = 80 种先天命格

- 出身由「地域风土」与「门第阶层」两组表格正交生成，各带独立的属性偏移与性格词条。
  - 先秦汉唐：关中秦川、齐鲁之邦、荆楚云梦、江南会稽、陇西凉州、中原洛邑、燕赵之地、巴蜀成都
    × 没落公族后裔、老秦耕战农卒、齐鲁经学儒士、临淄盐铁巨贾、大唐西市胡商……
  - 宋韵明清：汴京宣德门、江南姑苏、泉州刺桐港、徽州休宁、直隶顺天、天府成都、山陕商道、广州十三行 × 江南织造机户、徽州儒商门第、晋商票号伙计、边镇军户……
  - 近代破晓：上海租界、江南水乡、华北平原、东北煤城、西南山城、西北军垦、岭南侨乡、北平皇城根 × 纱厂职员门第、乡间佃农、铁路工人、中医坐堂、邮政信差……
- 因此同一个纪元里，**你不会两次投胎到同一个家**。

### 3. 十六阶段人生关口（年龄亦随机）

- 人生划分为 16 个关隘：幼年启蒙、童年韶光、少年分流、成人立志、青春韶华、初涉人世、成家立业、
  三十而立、负重前行、中年险滩、动荡考验、知命之年、花甲在望、桑榆晚景、古稀沧桑、夕阳辞章。
- **每个关口的年龄都是随机的**（例如「少年分流」可能落在 14 岁也可能落在 16 岁），只保证严格递增。
- **每个关口有 2 个互不相同的候选事件**，每个事件提供 2 条路线——稳妥持中（100% 必成）与锐意进取（掷骰博弈）。
  三纪元各 32 个事件，加上当代与未来两套旧事件池，全集共 400+ 个事件、800+ 个选项。

### 4. 强随机性（Stochastic Dice Mechanics）

- **实时胜率与掷骰判定**：博弈路线由智识、体魄、气运与性格特质动态修正，现场 Roll 点（1–100）。
- **突发偶发事件**：岁月流转间有几率遭遇无常变故。古代是里正催粮、边烽急报、市集奇货；
  当代是街头彩票、深夜急诊、老友借贷；未来是神经脉冲震荡、暗网算力空投、超额碳排罚单。

### 5. 人生轨迹与社会坐标（终身动态研判）

- 每一次抉择都会累积到五条赛道：**体制政务 / 商海实业 / 学术科技 / 文艺江湖 / 守拙布衣**。
  典故词汇（科举、征辟、商号、票号、抄书、归隐、夜校、车间、聚变……）均已纳入研判。
- 终身社会坐标随境遇实时变动：时代领军巨擘 → 德高望重栋梁 → 殷实一方富户 → 小康体面人家 → 风雨坚韧布衣。

### 6. 深刻终局：人物一生总结系统

- **六维数据终生量化**：生命健康、财富净值、学识心智、心境安宁、终生气运、声名威望。
  财富单位随纪元变化：**两金 / 两银 / 块银元 / 万元 / 信用点**，绝不让先秦人生出现「万元」。
- **纪元特色宿命评定与墓志铭**：古典纪元有《名标青史》《林泉散人》《明哲通达》《断弦流星》《烟火凡人》；
  当代有《时代弄潮翁》《负重攀登者》《旷达布衣》《清醒明哲者》；未来有《星海拓荒巨擘》《赛博齿轮》《文明先知》。
- **时代长河坐标评析**：标注出生之时的天下底色、一生穿越的每一重大时代、辞世之时的世道。
- **生平纪传与分水岭复盘**：自动生成万字级小说体纪传长卷，并列出每一个关键分水岭的掷骰实录与决策回响。

## 手机直接下载 / 添加到桌面体验方式（PWA App）

本项目已全面支持 **PWA（渐进式移动端应用）** 标准，无需通过应用商店，就能直接“下载/安装”到手机桌面，拥有原生 App 般的全屏体验与离线可用能力：

### 1. 开启 GitHub Pages 在线访问（最推荐，免局域网限制）
在 GitHub 仓库主页（`https://github.com/l1Ha/choice`）：
1. 点击 **Settings** ➔ 找到左侧 **Pages**；
2. 在 **Branch** 下选择 `main`，文件夹选择 `/ (root)`，点击 **Save**；
3. 等待约 1 分钟即可生成专属在线链接（如 `https://l1ha.github.io/choice/`）；
4. 用手机浏览器打开该网址即可。

### 2. 手机“下载安装到桌面”步骤：
- **苹果 iPhone / iPad（Safari 浏览器）**：
  1. 用 Safari 打开游戏页面；
  2. 点击浏览器底部正中间的 **分享按钮**（带有向上的小箭头方框图标）；
  3. 下滑选择 **“添加到主屏幕”（Add to Home Screen）**；
  4. 点击右上角“添加”，手机桌面上就会出现《浮生录》金色 App 图标，点击即全屏沉浸游玩，无浏览器网址栏干扰！
- **安卓 Android（Chrome / Edge / 微信 / 系统自带浏览器）**：
  1. 用手机浏览器打开游戏页面；
  2. 点击浏览器右上角或右下角“菜单”（三点或设置图标）；
  3. 点击 **“添加到主屏幕”** 或 **“安装应用”**；
  4. 安装后即可像原生 App 一样直接从桌面启动，并支持离线缓存运行。

## 本地启动与体验方式

本项目支持 **双端开箱即用**，均无任何第三方依赖。

### 方式一：网页端体验（推荐，视觉效果与 Web Audio 音效最佳）
直接在现代浏览器中打开 [index.html](index.html)：
- 拥有纸墨暗黑质感排版、六维实时属性栏、时代横幅提示、命运掷骰动效。
- 支持单选五大纪元之一，或一键【随机投掷时代与年月】。
- 内置零依赖离线 Web Audio 音效引擎，提供真实的抉择声与终局钟鸣。
- 支持一键将“人物一生生平长卷档案”复制到系统剪贴板。

也可以使用本地静态服务器启动：
```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

### 方式二：终端命令行体验（纯 Python 3，零外部依赖）
在终端中直接运行 [life_game.py](life_game.py)：
```bash
python3 life_game.py
```
- 包含 ANSI 终端彩色排版、打字机节奏感输出、交互式掷骰检定与终局盖棺定论。
- 支持在终端中选择五大纪元之一，或让命运随机投掷。

## 内容维护与再生成（tools/）

`index.html` 与 `life_game.py` 中的纪元内容由 `tools/` 下的数据模块**生成**，
两边共享同一份内容源，确保 Web 与 CLI 叙事完全一致。

```
tools/
  civ_core.py            五大纪元配置、42 段连续时代表、JS/Python 代码生成器
  civ_loader.py           分片装配与校验（8 地域 / 10 门第 / 16 阶段 / 每阶段 ≥2 事件）
  civ_meta_<纪元>.py      该纪元的 8 地域 + 10 门第
  civ_stages_<纪元>_<k>.py 该纪元第 4k..4k+3 个生命阶段的事件（每阶段 2 个）
  build_5epoch_js.py      生成 index.html
  build_5epoch_py.py      生成 life_game.py
  verify_web.js           在 Node 中以最小 DOM 模拟跑通全流程自检
```

重新生成（会基于当前 `index.html` / `life_game.py` 原文进行注入，请先确保二者处于未注入状态，
例如 `git checkout -- index.html life_game.py`）：

```bash
python3 tools/build_5epoch_js.py   # 注入 index.html
python3 tools/build_5epoch_py.py   # 注入 life_game.py
```

自检：

```bash
python3 -c "import ast; ast.parse(open('life_game.py', encoding='utf-8').read()); print('OK')"
node tools/verify_web.js           # 需 Node.js：语法检查 + 400 事件/800 选项校验 + 100 条完整人生模拟
```

> 注意：网页端若已安装为 PWA，更新后请在浏览器中刷新一次（Service Worker 缓存版本号已随内容递增）。
