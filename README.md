1. 点击 **Settings** ➔ 找到左侧 **Pages**；
2. 在 **Branch** 下选择 `main`，文件夹选择 `/ (root)`，点击 **Save**；
3. 等待约 1 分钟即可生成专属在线链接（如 `https://l1ha.github.io/choice/`）；
4. 用手机浏览器打开该网址即可。

### 2. 手机“下载安装到桌面”步骤：
- **苹果 iPhone / iPad（Safari 浏览器）**：
  1. 用 Safari 打开游戏页面；
  2. 点击浏览器底部正中间的 **分享按钮**（带有向上的小箭头方框图标）；
  3. 下滑选择 **“添加到主屏幕”（Add to Home Screen）**；
  4. 点击右上角“添加”，手机桌面上就会出现《浮生录》金色 App 图标，点击即全屏沉浸游玩，无浏览器网址栏干扰！
- **安卓 Android（Chrome / Edge / 微信 / 系统自带浏览器）**：
  1. 用手机浏览器打开游戏页面；
  2. 点击浏览器右上角或右下角“菜单”（三点或设置图标）；
  3. 点击 **“添加到主屏幕”** 或 **“安装应用”**；
  4. 安装后即可像原生 App 一样直接从桌面启动，并支持离线缓存运行。

## 本地启动与体验方式

本项目支持 **双端开箱即用**，均无任何第三方依赖。

### 方式一：网页端体验（推荐，视觉效果与 Web Audio 音效最佳）
直接在现代浏览器中打开 [index.html](index.html)：
- 拥有纸墨暗黑质感排版、六维实时属性栏、时代横幅提示、命运掷骰动效。
- 支持单选五大纪元之一，或一键【随机投掷时代与年月】。
- 内置零依赖离线 Web Audio 音效引擎，提供真实的抉择声与终局钟鸣。
- 支持一键将“人物一生生平长卷档案”复制到系统剪贴板。

也可以使用本地静态服务器启动：
```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

### 方式二：终端命令行体验（纯 Python 3，零外部依赖）
在终端中直接运行 [life_game.py](life_game.py)：
```bash
python3 life_game.py
```
- 包含 ANSI 终端彩色排版、打字机节奏感输出、交互式掷骰检定与终局盖棺定论。
- 支持在终端中选择五大纪元之一，或让命运随机投掷。

## 数据层架构与再生成（tools/）

本项目采用**引擎与数据层解耦**的先进架构：
- 网页端引擎位于 [index.html](index.html)，数据层自动生成于 [data/epochs.js](data/epochs.js)（由 PWA Service Worker 离线缓存）。
- 终端引擎位于 [life_game.py](life_game.py)，数据层自动生成于 [fsl_epochs.py](fsl_epochs.py)。
- 双端共用 `tools/civ_*.py` 与 `tools/civ_women_*.py` 原始史实与科幻内容源，确保两端数值与文本绝对同步。

```
tools/
  civ_core.py             五大纪元配置、43 段连续时代表、JS/Python 代码生成器
  civ_loader.py            分片装配与校验（8 地域 / 10 门第 / 16 阶段 / 每阶段 ≥2 事件）
  civ_meta_<纪元>.py       该纪元的 8 地域 + 10 门第
  civ_stages_<纪元>_<k>.py  该纪元通用生命阶段事件池
  civ_women_<纪元>.py       该纪元女性专属生命处境事件池（5 大纪元 × 8 阶段）
  epoch_pack.py            双端代码包构建中枢（加载数据、生成事件与称谓）
  build_epochs_data.py     生成 data/epochs.js
  build_epochs_data_py.py  生成 fsl_epochs.py
  verify_web.js            Node 虚拟 DOM 全流程自检（语法 + 校验 + 100条人生模拟）
```

重新生成两端数据层（修改 `tools/` 内容后随时执行）：

```bash
python3 tools/build_epochs_data.py     # 刷新 data/epochs.js
python3 tools/build_epochs_data_py.py  # 刷新 fsl_epochs.py
```

自检命令：

```bash
python3 -c "import ast; ast.parse(open('life_game.py', encoding='utf-8').read()); print('OK')"
node tools/verify_web.js               # 语法检查 + 400通用事件 + 40女性专属事件 + 100条完整人生模拟
```

> 注意：网页端若已安装为 PWA，更新后请在浏览器中刷新一次（Service Worker 缓存版本号为 `fushenglu-v7`）。
