# 《浮生录》（Lifepath）· 时代浪潮与真实文字人生模拟器

> “一个人的命运，既要靠自我的奋斗，亦要看历史的进程。时代洪流呼啸而过，偶发的幸与不幸如影随形。唯心自守，落子无悔。”

---

## 核心系统与全新特性

### 1. 穿梭过去与未来的双纪元降生系统（自主挑选 / 天命随机）
- **过去历史纪元（1976-1994）**：
  - 投胎年代：1976（文革暮年）、1982（改革春风）、1988（商品狂潮）、1994（南巡下海潮）。
  - 家庭底色：三线内陆国企大院、黄土丘陵偏远农家、省城书香教师、沿海敢闯个体户等。
  - 时代脉络：国企改制、物价闯关、千禧加入WTO、四万亿基建、学区房暴涨、移动互联百团大战与大厂优化。
- **近未来科幻纪元（2042-2060）**：
  - 深度构思未来科技与社会演进方向：常温超导、商业聚变能源、人造电离穹顶、脑机神经接口、碳排放税配额、地月货运电梯、谷神星小行星采矿、CRISPR-IV 代际基因编辑、思维云端备份与数字永生法案、强人工智能自组织与超强太阳风暴。
  - 未来家庭底色：低轨空间站空港维修工、次级穹顶边缘生态水培农场、跨国巨企算力中继基层职员、地下自由频段游民守望者等。
- **时代自由选择与随机投掷**：开局可自主勾选【过去风云纪元】或【未来科幻纪元】，亦可一键让命运掷骰随机决定你的降生时代。

### 2. 丰富饱满的 16 阶段人生关口与时代缩影
- 游戏将人生精细划分为 16 个重要关隘（6岁、10岁、15岁、18岁、21岁、24岁、27岁、31岁、35岁、40岁、44岁、50岁、58岁、66岁、74岁、80岁），贯穿人生的每一个分水岭。
- 每一个阶段的选择都紧扣宏大时代背景的沉浮，并提供稳妥路线与高收益高风险博弈路线。

### 3. 强随机性（Stochastic Dice Mechanics）
- **实时胜率与掷骰判定**：选项分为“确定性稳扎稳打”（100%必成）与“博弈冒险”（带成功率，由智识、体魄、气运与特质动态修正），实时现场 Roll 点判定（1-100）。顺遂则跃升阶层，受挫则陷入被动。
- **突发偶发事件（Random Encounters）**：岁月流转间有 32% 几率遭遇突发的无常变故：
  - 过去纪元：街头彩票小奖、深夜急诊惊魂、老友借贷失联、业内贵人提携、股市大盘剧震等；
  - 未来纪元：神经脉冲微频震荡、暗网匿名算力空投、仿生合成蛋白污染召回、火星退役老兵指点、超额碳排放罚单等。

### 4. 深刻终局：人物一生总结系统
- **五维数据终生量化**：生命健康（Health）、积累财富净值（Wealth，支持负债统计）、学识智识（Wisdom）、心境安宁（Peace）、天命气运（Fortune）。
- **纪元特色宿命评定与墓志铭**：
  - 过去历史纪元：《时代弄潮翁》、《负重攀登者》、《旷达布衣》、《清醒明哲者》、《断弦流星》、《人间守望者》；
  - 未来科幻纪元：《星海拓荒巨擘》、《赛博齿轮》、《纯粹碳基散人》、《文明先知》、《星轨流星》、《星尘守夜人》。
- **时代坐标长河评析**：宏观剖析主角在时代大浪淘沙中的个人位置（大历史 × 小人物）。
- **生平纪传与分水岭复盘**：自动生成生动的小说纪传体长卷，并列出每一个关键分水岭的掷骰实录与决策回响。

## 手机直接下载 / 添加到桌面体验方式（PWA App）

本项目已全面支持 **PWA（渐进式移动端应用）** 标准，无需通过应用商店，就能直接“下载/安装”到手机桌面，拥有原生 App 般的全屏体验与离线可用能力：

### 1. 开启 GitHub Pages 在线访问（最推荐，免局域网限制）
在 GitHub 仓库主页（`https://github.com/l1Ha/choice`）：
1. 点击 **Settings** ➔ 找到左侧 **Pages**；
2. 在 **Branch** 下选择 `main`，文件夹选择 `/ (root)`，点击 **Save**；
3. 等待约 1 分钟即可生成专属在线链接（如 `https://l1ha.github.io/choice/`）；
4. 用手机浏览器打开该网址即可。

### 2. 手机“下载安装到桌面”步骤：
- **苹果 iPhone / iPad（Safari 浏览器）**：
  1. 用 Safari 打开游戏页面；
  2. 点击浏览器底部正中间的 **分享按钮**（带有向上的小箭头方框图标）；
  3. 下滑选择 **“添加到主屏幕”（Add to Home Screen）**；
  4. 点击右上角“添加”，手机桌面上就会出现《浮生录》金色 App 图标，点击即全屏沉浸游玩，无浏览器网址栏干扰！
- **安卓 Android（Chrome / Edge / 微信 / 系统自带浏览器）**：
  1. 用手机浏览器打开游戏页面；
  2. 点击浏览器右上角或右下角“菜单”（三点或设置图标）；
  3. 点击 **“添加到主屏幕”** 或 **“安装应用”**；
  4. 安装后即可像原生 App 一样直接从桌面启动，并支持离线缓存运行。

## 本地启动与体验方式

本项目支持 **双端开箱即用**，均无任何第三方依赖。

### 方式一：网页端体验（推荐，视觉效果与 Web Audio 音效最佳）
直接在现代浏览器中打开 [index.html](index.html)：
- 拥有纸墨暗黑质感排版、六维实时属性栏、时代横幅提示、命运掷骰动效。
- 支持单选【过去纪元】、【未来纪元】或一键【随机投掷时代】。
- 内置零依赖离线 Web Audio 音效引擎，提供真实的抉择声与终局钟鸣。
- 支持一键将“人物一生生平长卷档案”复制到系统剪贴板。

也可以使用本地静态服务器启动：
```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```

### 方式二：终端命令行体验（纯 Python 3，零外部依赖）
在终端中直接运行 [life_game.py](life_game.py)：
```bash
python3 life_game.py
```
- 包含 ANSI 终端彩色排版、打字机节奏感输出、交互式掷骰检定与终局盖棺定论。
- 支持在终端中选择纪元模式（过去 / 未来 / 随机）。
